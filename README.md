# Wittle Alien

Launch site for [Wittle Alien](https://wittlealien.com), a Christian kids' media brand of picture books, worship songs, and animated stories.

The signup form stays in the browser. It does not send email anywhere. After a valid address is entered, the page confirms and offers a black-and-white coloring page traced from the mascot.

```bash
npm install
npm run dev
npm run build
```
